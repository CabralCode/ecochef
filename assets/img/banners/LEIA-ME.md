# Imagens dos banners

Salve cada imagem nesta pasta com o nome abaixo. Enquanto o arquivo não existir, aparece o placeholder "Imagem do banner".

- Formato: WebP (qualidade 75 a 80)
- Tamanho: **1600 × 900 px** (proporção 16:9). A imagem ocupa a metade direita do banner no computador
  e vira fundo esmaecido no celular, onde é cortada num quadrado central.
- Mantenha o prato dentro do quadrado central (900 × 900 px) e não escreva texto na foto: o título vem do código.
- Peso alvo: até 180 KB

| Arquivo | Uso |
|---|---|
| `halloween.webp` | ilustração em código (não precisa de imagem) |
| `carne-louca-de-casca-de-banana.webp` | banner de receita |
| `bolo-de-banana-bem-madura.webp` | banner de receita |
| `points.webp` | ilustração em código (não precisa de imagem) |
| `pudim-de-pao-amanhecido.webp` | banner de receita |
| `molho-de-tomate-maduro.webp` | banner de receita |
| `caldo-de-frango-com-carcaca.webp` | banner de receita |

Para criar um banner novo, adicione um item em `js/data/banners.js` e salve a imagem com o mesmo `id`.
